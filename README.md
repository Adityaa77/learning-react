# Learning React 

This repository contains my personal projects and exercises while learning **React.js**.  
The purpose of this repo was to practice and consolidate React concepts and build small components and applications.

## Learning Timeline

I actively worked on these projects from **January 30, 2025, to February 18, 2025**. During this period, I followed tutorials from:
- **Chai Aur Code**  
- **Bro Code**  

## What’s Inside
The repo includes multiple small React projects and components to practice different concepts:
- Header & Footer components  
- Cards & Prop handling  
- To-Do List application  
- Counter & Digital Clock components  
- Conditional rendering examples  
- Background color picker  
- Basic styling using CSS modules  

All code is structured for learning purposes and to track progress while following the tutorials.

## Tech Stack
- React.js  
- JavaScript (ES6+)  
- CSS / CSS Modules  
- Vite (for project setup)
